Microsoft Teams Audio QuickFix Helper

Deutsch

Diese Seite hilft Ihnen, schnell einen Befehl auszufuhren, um die Audiofunktion in Microsoft Teams neu zu laden.

  1. Klicken Sie auf Befehl kopieren
  2. Offnen Sie PowerShell als aktueller Benutzer
  3. Fugen Sie den Befehl ein und drucken Sie Enter

Diesen Befehl ausfuhren

Get-Process -Name "ms-teams","Teams" -ErrorAction SilentlyContinue | Stop-Process -Force; Start-Process "ms-settings:sound"

English

This page helps you quickly run one command for common Microsoft Teams audio refresh needs.

  1. Click Copy Command
  2. Open PowerShell as your current user
  3. Paste the command and press Enter

Run This Command

Get-Process -Name "ms-teams","Teams" -ErrorAction SilentlyContinue | Stop-Process -Force; Start-Process "ms-settings:sound"
